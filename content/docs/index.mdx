# Welcome to aoe2-ui

**aoe2-ui** is an open-source UI component library that brings the iconic visual style of classic Age of Empires II to modern web applications. Whether you're building a fan project, a gaming community site, or just want that nostalgic RTS aesthetic, this library has you covered.

## What is aoe2-ui?

This project provides a collection of UI components inspired by the timeless design language of Age of Empires II, featuring parchment textures, stone and wood frames, gold accents, and the medieval aesthetic that defined the genre.

All components are designed to be **copy-paste ready** and work seamlessly with modern frameworks like React, Next.js, and more.
